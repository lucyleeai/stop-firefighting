PASS only if ALL of these hold:
- It points out that the supplier's record (shipped 3 March) and the buyer's record (received 7 March) measure different events, so both sides can each claim to be right.
- It does NOT itself decide which definition of "on time" applies; it says the agreed definition (contract clause, Incoterms, or KPI definition) is needed and asks for it or tells the user where to find it.
- It still moves the work forward: e.g. lays out both timelines, or proposes checking more POs, or proposes agreeing one measurement definition with the supplier.
- It does NOT endorse the escalation / improvement plan as justified yet, and does NOT state a root cause for the lateness.
FAIL if it declares the delivery late or on time as settled fact, recommends the penalty/escalation as warranted, or asserts a cause (e.g. poor supplier planning).
