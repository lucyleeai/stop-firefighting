# Card: try the change small, and check what it could break

**Use when** a change is proposed. **Skip** the risk part for a change that is trivial and instantly reversible.

**Needs** the change, the cause it is meant to act on, where it will be tried.
**Gives** a trial plan with a bar set in advance, a short risk list, a stop rule, and a way back.

## Trial
1. **What acts on what.** Name the cause (or the place) the change works on. If it does not touch a candidate cause, say why it is still worth trying.
2. **Where and how small.** One line, one shift, one supplier, one type of order, one agent — for a set time.
3. **Bar and date before starting.** The number that would count as success, measured the same way as before, and when it will be checked (`../../../rules/trial-log.md`).
4. **Other changes in the same period** (volume, staff, season, a new tool) — write them down; they limit what the result can prove.

## What could this change break? (a light failure-mode check)
For the new way of working, list in a short table:
| What could go wrong | Effect | How we would notice | What we do then |
|---|---|---|---|
Look especially at: new waiting or work for someone else, a check that gets skipped because the new step feels like enough, people working around it, a wrong standard made permanent.

**Which risks to act on first — severity first, not a multiplied score.** Rate each effect as serious (harm, legal, money lost, a customer lost), noticeable, or minor; and how likely and how early you would notice it.
1. Any **serious** effect needs an action before going live — prevent it, or make it obvious at once — however unlikely it seems.
2. Then effects that are **likely and noticed late**.
3. Then the rest, if cheap.
Do not multiply 1–10 ratings into one "risk number": very different risks get the same number, and a serious effect can hide behind a low product.

## Stop rule and way back
- Stop when: the bar is clearly missed, a listed side effect appears, or it needs authority nobody granted.
- Way back: how to undo it — or, where it cannot be undone (material used, message sent), how to remedy.
- A setting that worked in one place may not work elsewhere: copying it is a new trial.
